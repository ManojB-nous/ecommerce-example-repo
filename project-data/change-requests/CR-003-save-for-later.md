# CR-003 – "Save for later" from checkout
Raised 2026-10-11 by Marketing · Status: Deferred to post-launch backlog (not in SOW; estimated 7 person-days).
## Request
Allow a customer to move items to a "saved for later" list from the checkout screens, so a cart can be paused without losing it.
## Impact
| Area | Impact |
|------|--------|
| Scope | Not in the SOW; adds a new list, storage and screen |
| Effort | 7 person-days (above the 5 person-day threshold, so Chief Digital Officer approval is needed) |
| Timeline | Would compete with payment retry and accessibility work before the design freeze |
| Compliance | No new personal data beyond the cart; consent wording not required |
## Decision
Deferred to the post-launch backlog. Revisit after 100% rollout.
